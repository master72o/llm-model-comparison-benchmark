# Figures Directory

This directory contains visual comparison charts generated by the Multi-Model Benchmark suite:
- `model_overall_performance.png`: Bar chart comparing Overall Quality Score and Format Compliance Rate across models (`gpt-4o`, `claude-3-5-sonnet`, `llama-3-70b`, `mistral-large`, `gemini-1-5-pro`).
- `pareto_cost_vs_quality.png`: Scatter plot mapping Cost ($/10,000 tasks) vs Overall Quality Score with Pareto Efficiency Frontier curves.
- `domain_performance_radar.png`: Grouped bar chart comparing model capabilities across domains (Reasoning, Structured Output, Multilingual, Code Generation).
